# Projet1_toys_and_models

Toys and models : Analyse de Données et Tableau de Bord Interactif avec SQL et Power BI  
Aperçu du Projet  
Ce projet présente un exemple complet de la manière dont les données peuvent être extraites, transformées et visualisées pour fournir des informations significatives. En utilisant SQL pour la manipulation et l'analyse des données et Power BI pour la création de tableaux de bord interactifs, j'ai démontré comment transformer des données brutes en informations exploitables. L'objectif était de créer une solution de business intelligence robuste qui permet aux utilisateurs d'explorer les tendances, d'identifier les modèles et de soutenir les décisions stratégiques.  
  
Fonctionnalités Clés  
Extraction et Nettoyage des Données avec SQL : Scripts SQL avancés pour une extraction efficace des données provenant de diverses sources, suivis de processus de nettoyage et de transformation pour garantir l'intégrité et la cohérence des données.  
Analyse Détaillée des Données : Implémentation de requêtes SQL complexes pour mener des analyses approfondies, calculer des métriques clés et préparer les données pour la modélisation dans Power BI.  
Modélisation des Données dans Power BI : Création d'un modèle de données optimisé dans Power BI, établissant des relations efficaces entre les tables pour améliorer les performances et la scalabilité du tableau de bord.  
Tableau de Bord Interactif et Dynamique : Développement d'un tableau de bord Power BI intuitif et visuellement attrayant, qui comprend des graphiques, des tableaux et des filtres interactifs pour une navigation et une exploration des données sans effort.  
Insights Actionnables : Le tableau de bord est conçu pour mettre en évidence les tendances, les anomalies et les opportunités, offrant une compréhension claire des performances et soutenant la prise de décisions basée sur les données.  
  
Stack Technologique  
Base de données : MySQL  
Langage de Requête : SQL  
Outil de Business Intelligence : Microsoft Power BI Desktop
